SISTEMA UVA - INSTALACIÓN LOCAL

Requisitos
  - Windows 10/11 de 64 bits, 8 GB de RAM (16 recomendados), 8 GB libres en disco (15 recomendados).
  - Docker Desktop instalado y abierto al menos una vez (el instalador ofrece instalarlo).

Accesos (menú Inicio > Sistema UVA)
  Sistema UVA ............... abre el sistema en el navegador
  Administrador de Odoo ..... backoffice (usuario admin, ver "Datos de acceso")
  App de campo (tablets) .... app de los verificadores (también en el escritorio)
  Certificado para tablets .. carpeta con Certificado-tablets-Asercontrol.crt
  Iniciar / Detener ......... arranca o detiene los servicios
  Respaldar base de datos ... copia base de datos y adjuntos a la carpeta respaldos\
  Desinstalar ............... quita el sistema (pregunta si conservar los datos)

Si el sistema ya estaba instalado, el instalador pregunta qué hacer:
  Actualizar todo        - instala la versión nueva en la web, Odoo y la app. Respalda la base y
                           conserva clientes, visitas y usuarios.
  Reinstalar desde cero  - guarda un respaldo en Documentos, borra la instalación anterior con
                           todos sus datos e instala la versión nueva limpia (pide confirmación).
  Solo la app            - actualiza solo la app de campo; la web, Odoo y los datos no cambian.
  Cancelar               - salir sin hacer cambios.

El sistema arranca solo al iniciar sesión en Windows (si Docker Desktop está configurado para
iniciar con Windows). Las contraseñas generadas están en CREDENCIALES.txt.

Línea de comandos (PowerShell, en esta carpeta):
  .\uva.ps1 estado | iniciar | detener | respaldar | actualizar | renovar-clave | desinstalar
  .\uva.ps1 abrir-app | agregar-app | regenerar-certificado

App de campo en teléfonos y tablets (misma red que este equipo)
  Se instala desde el propio teléfono o tablet (Android, iPhone o iPad), sin cables ni códigos QR:
  1. En Chrome (Android) o Safari (iPhone/iPad) escribe la dirección de la web CON http://,
     por ejemplo  http://192.168.1.50:8080  (la exacta está en CREDENCIALES.txt y en la web,
     menú «App de campo (móvil)»).
  2. Inicia sesión y abre el menú > «App de campo (móvil)». Aparece «Instalar la app en este
     teléfono» con 3 botones: permiso de seguridad, abrir la app y entrar.
  3. Entra con un usuario de Odoo ligado a un verificador (Sistema UVA > Verificadores). La app se
     conecta sola al servidor, guarda todo en el teléfono y envía lo capturado al reconectar.
  Antes, una sola vez, permite el acceso desde la red (PowerShell como administrador; ver la guía
  rápida, punto 6). Si cambia la IP de este equipo: .\uva.ps1 regenerar-certificado.
  Conviene fijar una IP para este equipo en el router.

Uso desde otros equipos de la red: abre http://<nombre-o-IP-de-este-equipo>:<puerto del sistema>
y permite el puerto en el Firewall de Windows si se solicita.
